# Sigma 20–200mm F3.5–6.3 DG DN Contemporary — custom Lensfun profile

`local-sigma-20-200.xml` is a **user-generated calibration profile**, not part of
the upstream Lensfun database.

## Provenance

- Derived from Sony in-camera MakerNote correction metadata extracted from 207
  ARW frames shot on a Sony ILCE-7CM2 with the Sigma 20-200mm F3.5-6.3 DG DN
  Contemporary.
- MakerNote LUTs decoded with darktable's formulas; polynomial fits and Lensfun
  XML generated by the `sigma_lens_profile` project (`scripts/03_fit_lensfun.py`).
- Coordinate convention: Sony LUTs are radial in the half-diagonal-normalised
  radius (r = 1 at the corner). Distortion and TCA coefficients are converted to
  Lensfun's convention (`k1_xml = k1_sony / s²`, `k2_xml = k2_sony / s⁴`,
  s² = 3.25 for 3:2 full frame). All distortion entries use the single poly5
  model family.
- Validated against the real lensfun-rs modifier (pinned rev `579679a`) and the
  upstream C++ Lensfun probe; the two agree within 1e-3 px on the regenerated
  profile.
