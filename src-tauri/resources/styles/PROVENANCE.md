# RapidRoom Styles v1

These eleven recipes are original RapidRoom designs, authored directly as native tone, HSL, grading, vignette and grain controls for issue308. No commercial preset, Lightroom preset file or imported preset values were used. Names describe visual intent; film names do not claim to reproduce a particular film stock or manufacturer.

Each style contains a shaped luma curve, multiple tone controls, an HSL palette, grading and finishing controls. The two monochrome designs use colour-channel luminance and neutral grading luminance instead of a coloured split tone. Styles preserve the photo's exposure, camera white balance, crop, lens choice, sharpening and noise-reduction settings. Owned effect panels are enabled when the style is applied. Stable IDs retain favourites and moved presets across library loads.

Amount blends from the edit before application. A grading wheel fading from neutral retains its intended hue while saturation fades, and two coloured wheels follow the shortest hue arc. Both active curves and saved point curves are included so the editor and renderer retain the same tone shaping.

Private owner-photo review stays outside this repository. Public evidence must use CC0 sources. Taste acceptance and rendering validation are required before shipping this draft pack.
